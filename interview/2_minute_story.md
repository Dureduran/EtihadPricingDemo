# Ancillary Pricing Production Lab — 2-minute story

Independent portfolio prototype using synthetic and public data. No Etihad internal data, systems or proprietary pricing logic are used.

Start with:

"Etihad already has an in-house ancillary dynamic-pricing capability, so I didn't want to build another dashboard that simply predicts a price. I built a small production lab showing how I would evaluate a new pricing model against the current approach, introduce it safely, measure its commercial impact and monitor whether it should remain live."

Then show:

**Price Explanation**  
"Here is why the New Model recommends a different extra-legroom price than Current Pricing on AUH–LHR Economy Basic, four days out."

**Pricing Controls**  
"Revenue Management controls where and how aggressively it can operate — traffic percent, price band, pause, or Return to Current Pricing. Not per-passenger approval."

**Pricing Test Results**  
"We measure whether it actually increases revenue without damaging conversion. These numbers are a simulated result using synthetic and public data."

**Production Monitor**  
"If customer behaviour changes or model quality deteriorates, we HOLD expansion or Return to Current Pricing. Checkout still has a fallback: New Model → Current Pricing → simple rules → safe fixed price."

Done. Do not open with Doha, RASK, or overbooking.
